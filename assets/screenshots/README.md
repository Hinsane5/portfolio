# Project Screenshots

Drop project images here. They're optimized into the Next.js `public/` folder at
build time and lazy-loaded via `next/image`.

Suggested files (any project with no image renders a sized placeholder):

| Project | Suggested screenshots |
|---|---|
| ArCane Ring | gameplay shot(s) |
| RUSA Internal | administrator dashboard |
| hoshiBmaTchi | home feed, settings, saved collection |
| Hwixel | dashboard, analytics, task board, peer-evaluation (phone frames) |
| WarungAI | owner dashboard |

**Guidance**
- Prefer source PNGs here; the build converts to WebP/AVIF.
- Name by project id, e.g. `arcane-ring-01.png`, `rusa-internal-dashboard.png`.
- Wide screenshots ~1600px on the long edge are plenty.
